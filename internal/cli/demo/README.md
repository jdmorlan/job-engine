# Example jobs

Four jobs, each showing one idea. They are ordinary files: read them, change
them, break them. Nothing here is special to the engine.

  demo-hello    the smallest job that exists
  demo-counter  a durable cursor, advanced on success
  demo-flaky    the same, but failing -- watch the cursor not move
  demo-tick     a schedule, so the daemon has something to do

Remove them all with: je demo --remove
